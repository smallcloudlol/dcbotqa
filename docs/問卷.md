# 問卷設計

建議用 Google 表單製作，量表題使用「線性刻度 1～5」（1 = 非常不同意，5 = 非常同意）。

> ⚠️ 量表題的**題目標題請保留題號**（例如「A1. 我覺得…」），`tools/analyze_survey.py` 會依題號開頭的字母分組計算。

## 第一部分：基本資料

1. 年級／身分：＿＿＿＿
2. 平常使用 Discord 的頻率：每天／每週數次／偶爾／幾乎不用
3. 是否使用過其他 Discord Bot：是／否

## 第二部分：接受程度（A）

- A1. 我覺得透過 Discord Bot 進行問答是新穎有趣的方式。
- A2. 我能很快了解 Bot 的指令與操作方式。
- A3. 我覺得用按鈕作答比打字作答方便。
- A4. 我覺得 Bot 的題目與選項呈現清楚易懂。
- A5. 整體而言，我能接受以 Discord Bot 作為問答學習的工具。

## 第三部分：互動體驗（B）

- B1. 作答後立即顯示對錯與解析，對我有幫助。
- B2. 倒數計時讓答題更有緊張感與趣味。
- B3. 得分明細與連續答對加分讓我更有動力繼續作答。
- B4. 排行榜讓我想爭取更好的名次。
- B5. 多人挑戰（/challenge）增加了我與其他成員的互動。
- B6. Bot 回應流暢，沒有明顯延遲或錯誤。

## 第四部分：使用意願（C）

- C1. 我願意在未來繼續使用這個問答 Bot。
- C2. 如果課程或社群提供這類 Bot，我會主動參與。
- C3. 我願意推薦這個 Bot 給朋友或同學。
- C4. 比起紙本或表單測驗，我更願意用 Discord Bot 作答。

## 第五部分：開放式問題

1. 你最喜歡 Bot 的哪個功能？為什麼？
2. 使用過程中遇到什麼問題或不方便的地方？
3. 對這個 Bot 有什麼建議或希望新增的功能？

## 分析方式

1. Google 表單 →「回覆」→「下載回覆 (.csv)」
2. 執行：

   ```
   python tools/analyze_survey.py 問卷回覆.csv -o 問卷分析報告.md
   ```

3. 報告內容：
   - **構面總覽**：接受程度／互動體驗／使用意願各自的平均數、標準差、Cronbach's α（信度）
   - **各題明細**：每題的平均數、標準差與 1～5 分人數分布

解讀參考：平均數高於 3（中立）代表整體傾向同意；α ≥ 0.7 表示同一構面的題目一致性可接受。開放式問題請人工整理歸納，作為結論與未來改進的依據。
