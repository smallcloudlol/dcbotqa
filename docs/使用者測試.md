# 使用者測試

分為兩部分：**功能測試**確認每個功能照設計運作；**使用體驗**觀察真實使用者操作時的狀況。測試完請把「實際結果」與觀察紀錄填上，作為報告的佐證資料。

## 二、使用體驗

### 測試流程（每位受測者約 10 分鐘）

1. 簡短說明：「這是一個在 Discord 上答題的 Bot，請依照任務操作，過程中可以說出你的想法。」（不要事先教指令）
2. 任務 1：自己找出如何開始答題，並完成 3 題。
3. 任務 2：查看自己目前的排名。
4. 任務 3：和其他受測者一起完成一次 `/challenge`。
5. 填寫問卷（見 [問卷.md](問卷.md)）。

### 可觀察的重點

- 是否能自己發現 `/quiz`、`/help` 等斜線指令
- 倒數計時與按鈕上色的回饋是否被注意到、是否被理解
- 看到排行榜或連對加分後，是否主動想再多答幾題
- 手機與電腦操作是否有差異
- 作答紀錄可用 `/export_answers` 匯出，搭配觀察紀錄分析（例如平均作答時間、各分類正確率）
